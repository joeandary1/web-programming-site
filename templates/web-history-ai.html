History of the World Wide Web

Introduction

The World Wide Web is a system used to access webpages and information through the Internet. It was created by Tim Berners-Lee at CERN.

Key Milestones

1989 — Web Proposal

Tim Berners-Lee proposed a system for sharing information using hypertext.

Why it mattered: This idea became the World Wide Web.

Source: https://home.cern/science/computing/birth-web

1990 — First Web Technologies

Tim Berners-Lee developed HTML, HTTP, URLs, the first browser, and the first Web server.

Why it mattered: These technologies made the Web work as a complete system.

Source: https://home.cern/science/computing/birth-web

1993 — Web Becomes Free

CERN made Web technology freely available.

Why it mattered: This allowed people around the world to create websites and develop the Web.

Source: https://home.cern/science/computing/birth-web

1993 — Mosaic Browser

The Mosaic browser became popular.

Why it mattered: It made the Web easier for normal users to access.

Source: https://www.computerhistory.org/

1994 — W3C Created

Tim Berners-Lee founded the World Wide Web Consortium.

Why it mattered: W3C helped create common standards for Web technologies.

Source: https://www.w3.org/Consortium/

Three Key Web Technologies

HTML

Structures the content of webpages.

HTTP

Allows browsers and Web servers to communicate.

URL

Identifies the address of a resource on the Web.

Conclusion

The Internet and the World Wide Web are different.

The Internet is the network that connects computers and devices.

The World Wide Web is a system that uses the Internet to access websites and information.
